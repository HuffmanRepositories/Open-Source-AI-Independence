# First Contributions

New to this project or open source? Start here.

## Starter tasks
- Fix a typo or broken link.
- Improve a confusing paragraph.
- Suggest an existing standard or project.
- Add a question to an FAQ.
- Review the roadmap for missing priorities.
- Test navigation, accessibility, or onboarding.
- Explain a concept in beginner-friendly language.

## Getting started
1. Read README and Code of Conduct.
2. Search for a starter issue or ask for one.
3. Comment before taking on a task.
4. Make a small change and open a PR.
5. Explain what changed and how you checked it.

You do not need to be an expert. Thoughtful questions are contributions too.
