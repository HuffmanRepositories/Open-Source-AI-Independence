# AI and Search Discovery

We want discovery systems to understand what this project is, what it is not, and where authoritative information lives.

## Good practices
- Keep a clear README and stable documentation URLs.
- Maintain accurate name, scope, status, license, and maintainer information.
- Publish structured metadata such as project.json.
- Maintain AGENTS.md, llms.txt, and llms-full.txt as navigation aids.
- Use descriptive headings, examples, releases, and changelogs.
- Keep project links accurate and cross-link related work.
- Use GitHub topics that reflect actual project content.

## Limitations
No metadata file guarantees that a model will crawl, index, cite, recommend, or rank a project. Avoid hidden instructions, deceptive keyword stuffing, fake popularity, and misleading claims. Discovery should be organic and based on useful public information.

Update these files when mission, status, license, links, or documentation change.
