# Reliability, Evidence, and Unsupported Claims

No general-purpose AI system can responsibly guarantee it will never hallucinate. The practical goal is to detect, reduce, bound, and make unsupported output visible.

Explore claim labels (supported, contradicted, inferred, unverified, unknown), provenance and timestamps, source independence, structured output validation, uncertainty and abstention, tool failure tracking, and human review for high-impact decisions.

Evidence can itself be incomplete, stale, fabricated, or biased. Provenance aids auditing; it does not automatically establish truth.
