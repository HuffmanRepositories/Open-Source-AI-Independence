# Interoperability

Make systems cooperate without requiring the same provider, framework, or runtime.

1. Inventory existing standards first.
2. Identify the smallest useful common interface.
3. Document adapters and capability differences.
4. Add compatibility tests and examples.
5. Make authentication, permissions, errors, and versioning explicit.
6. Preserve graceful failure and provider substitution.
7. Document semantic differences and information loss.

Interoperability requires shared meaning and security expectations—not just connected APIs.
